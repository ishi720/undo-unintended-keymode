# Undo Unintended Keymode

Caps Lock や IME の状態が意図せず切り替わったときに、デフォルトの状態へ戻す Windows 用の常駐ツール。タスクバーの通知領域に常駐します。

## 機能

| 項目 | デフォルト | 検知する切り替えの例 |
|---|---|---|
| Caps Lock | オフ | `Shift` + `Caps Lock` などで大文字入力になった |
| 日本語入力 (IME) | オン | 変換キーや `半角/全角` で IME のオン/オフが変わった |
| 入力モード | ひらがな | 全角カタカナ・全角英数などに変わった |
| 入力方式 | ローマ字入力 | `Alt` + `カタカナ/ひらがな` などでかな入力になった |

各項目は、ボタンで手動で戻すか、「自動で戻す」をオンにして自動で戻せます。「自動で戻す」の初期値はすべてオフです。

## 動作環境

- Windows 10 / 11
- .NET Framework 4.x（Windows に標準）
- Microsoft IME（入力方式の検知・復元は Microsoft IME の設定値を使用します）

## ビルド

`build.bat` を実行すると、Windows 標準の C# コンパイラ（csc.exe）で `UndoUnintendedKeymode.exe` を作成。Visual Studio は不要。

## 使い方

1. `UndoUnintendedKeymode.exe` を実行。
   - ※「Windows によって PC が保護されました」と表示された場合は、「詳細情報」→「実行」
2. 通知領域のアイコンを左クリック、または右クリックして「設定を開く」を選ぶと画面が開く。

### 画面

上段が「キーの状態」、下段が「設定」。

| 列 | 内容 |
|---|---|
| 現在の状態 | 今の状態を表示。デフォルトと異なる項目はオレンジ色。|
| デフォルト | 戻す先の状態 |
| 手動［元に戻す］ | その項目をデフォルトに戻す|
| 自動で戻す | オンにした項目は、デフォルトと異なる状態になると自動で戻す。いずれかがオンの間はアイコンが緑色。 |

| 設定 | 初期値 |
|---|---|
| 戻したときに通知する | オン |
| Windows の起動時に自動で起動 | オフ |

- 設定と「自動で戻す」の状態は、変更した時点で `%APPDATA%\UndoUnintendedKeymode\settings.ini` に保存される。

### 終了

アイコンを右クリックして「終了」
